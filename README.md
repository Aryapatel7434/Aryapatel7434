# 🗺️ Smart City Route Optimizer

### Graph-Based Shortest Path Visualizer

**Java • DSA • Java Swing**

A graph-based desktop application focused on visualizing shortest-path computation for city-routing scenarios.

### Core Algorithm

**Dijkstra's Algorithm + Priority Queue**

```text
Start Node
    ↓
Priority Queue
    ↓
Minimum Distance Node
    ↓
Relax Neighbours
    ↓
Update Distances
    ↓
Repeat
    ↓
Shortest Path
```

### Complexity

```text
Time Complexity: O(E log V)
```
